# Eklipse App Paciente

Aplicacion frontend en React + TypeScript + Vite para la experiencia inicial del paciente.

## Scripts

- `npm run dev`: levanta el entorno local
- `npm run build`: compila TypeScript y genera el build
- `npm run lint`: ejecuta ESLint
- `npm run preview`: sirve el build localmente

## Funcionalidad incluida en esta fase

- login con autenticacion simulada
- inicio protegido para paciente
- invitaciones y anuncios mock
- cierre de sesion
- base visual responsiva preparada para seguir creciendo
